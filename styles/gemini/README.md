## Usage

1. Make sure you have the [Stylus](https://github.com/openstyles/stylus) browser
   extension installed, then visit
   [this link](https://github.com/rose-pine/userstyles/raw/main/styles/gemini/rose-pine.user.less)
2. Configure your preferred accent color and theme variant
3. Click install on the top left

## Options

- **Main Chat Width:** Adjust the conversation container width (`Default`,
  `Regular`, `Medium`, `Large`, `Max`).
- **Disable Gemini Advance Upsell:** Hide the promotional upgrade container.
- **Disable Gemini Glow:** Turn off the background ambient glow effect.
- **Disable Gradient Fading:** Remove top and bottom scroll mask gradients in
  chat history and input area.
- **Disable Hallucination Disclaimer:** Hide the footnoted AI accuracy
  disclaimer message.
- **Disable Welcome Message:** Hide the standard Gemini splash text and sparkle
  greeting on new chats.
